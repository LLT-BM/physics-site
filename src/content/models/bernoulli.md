## Как пользоваться
Две сцены. **Труба Вентури**: широкое сечение, горловина, снова широкое. Частицы движутся со местной скоростью v = Q/A, поэтому в горловине они заметно ускоряются. Над трубой стоят пьезометры — столбы жидкости, высота которых равна давлению в этом сечении. Включите трубки Пито, и увидите второй набор столбов: они читают полный напор.

Главный переключатель — **«Реальная жидкость»**. Пока он выключен, сумма Бернулли постоянна, линия EGL строго горизонтальна, а все столбы Пито стоят на одном уровне. Включите — и EGL наклонится вниз, появится безвозвратная потеря давления, а давление после Вентури не восстановится полностью.

Вторая сцена — **истечение из бака**. Двигайте глубину отверстия и следите за дальностью струи: она максимальна, когда дырка ровно на середине глубины. Есть режим опорожнения, в котором уровень падает по-настоящему.

Три режима графика: давление и скорость по длине трубы, линии напора, и столбики слагаемых Бернулли по сечениям — самый наглядный способ увидеть, что сумма одна и та же.

## Физика

Для установившегося течения несжимаемой жидкости без трения вдоль линии тока:

**p + ½ρv² + ρgz = const**

Разделив на ρg, получаем напоры — длины, которые можно измерить линейкой:

**p/(ρg) + v²/(2g) + z = H**

Это пьезометрический, скоростной и геометрический напоры. Их сумма H — полный напор, его и показывает трубка Пито.

Второе уравнение — **неразрывность**: **A₁v₁ = A₂v₂**. Расход один и тот же, значит при уменьшении площади скорость растёт во столько же раз. Отсюда весь эффект Вентури: площадь меньше вчетверо → скорость вчетверо больше → скоростной напор в 16 раз больше → давление падает.

### Проверенные числа

При D₁ = 100 мм, D₂ = 50 мм, v₁ = 2 м/с, воде 20 °C (ρ = 998 кг/м³) и p₁ = 30 кПа избыточного:

| Величина | Значение |
|---|---|
| A₁ / A₂ | 78,54 / 19,635 см², отношение ровно 4 |
| v₂ | 8 м/с |
| Q | 15,708 л/с |
| ½ρ(v₂² − v₁²) | **29 940 Па** = 3,0581 м вод. ст. |
| p₂ | **60 Па** избыточного, то есть 6,13 мм вод. ст. |
| p₁/(ρg) | 3,06423 м |
| v₁²/(2g) | 0,203874 м |
| v₂²/(2g) | 3,261978 м |
| Сумма Бернулли во всех трёх сечениях | **3,268106039 м** |
| Трубки Пито | 31 996 Па в обоих сечениях — стоят на одном уровне |
| Re₁ / Re₂ | 199 202 / 398 403, турбулентно |

Столб в горловине практически исчезает — это и есть та самая «загадка Бернулли», которую видно глазами.

### Реальная жидкость: где равенство ломается

У настоящей жидкости есть вязкость. Полный напор убывает по Дарси–Вейсбаху:

**h_f = f·(L/D)·v²/(2g)**

Ламинарно f = 64/Re, турбулентно модель считает по Свами–Джейну с шероховатостью ε. Плюс местные потери: в сужении K·v₂²/(2g), а при расширении — **потеря Борда–Карно (v₂−v₃)²/(2g)**.

Проверенные результаты для тех же настроек (ε = 0,0015 мм, K = 0,05):

| Что | Значение |
|---|---|
| f₁ / h_f1 | 0,015682 / 0,019182 м |
| f₂ / h_f2 | 0,014046 / 0,274912 м |
| Потеря в сужении | 0,163099 м |
| Борда–Карно при внезапном расширении | **1,834862 м = 17 964 Па** |
| То же с плавным диффузором (K = 0,15) | 0,275229 м = 2694,6 Па |
| p₂ с потерями | **−1724,6 Па**, то есть разрежение 176 мм вод. ст. |
| p₃ с диффузором | ≈ 21,5 кПа, потеря **≈ 8,5 кПа** |
| p₃ без диффузора | ≈ 7,2 кПа, потеря **≈ 22,8 кПа** |

Числа 7171 и 22 440 Па — двухсегментная оценка, в которой трение считается только на прямых участках. Модель интегрирует Дарси–Вейсбаха по всей длине, включая конус и диффузор, где скорость меняется от 8 до 2 м/с, поэтому показывает примерно на 1,3 кПа больше. Расхождение — не ошибка, а полнота учёта: самотест сверяет результат с той же интегральной схемой на сетке в 12 раз мельче.

Отсюда практический вывод: **диффузор нужен**. Плавное расширение возвращает большую часть давления, внезапное — теряет её в вихрях. Разница между двумя режимами в этой модели — 15 кПа, то есть половина входного давления.

### Кавитация

Если абсолютное давление падает ниже давления насыщенных паров, жидкость вскипает прямо в потоке. Для воды 20 °C это 2,34 кПа абсолютных, то есть −98,99 кПа избыточного. При отношении площадей 4 и p₁ = 30 кПа порог наступает на **v₁ = 4,1512 м/с**. Модель подсвечивает кавитационную зону розовым и предупреждает, что Бернулли там уже неприменим: течение перестаёт быть однофазным и непрерывным.

### Торричелли

Скорость истечения из отверстия на глубине h под поверхностью:

**v = √(2gh)**

Это в точности скорость тела, свободно упавшего с высоты h, и она **не зависит от плотности** — ртуть и вода вытекают одинаково быстро. Проверка: h = 0,5 м → 3,13209 м/с; h = 1 м → 4,42945 м/с; h = 2 м → 6,26418 м/с.

Дальность струи при высоте отверстия y над полом:

**R = v·√(2y/g) = 2√(h·y)**

При фиксированном уровне H и y = H − h максимум достигается на **h = H/2** и равен ровно **H**. Модель показывает эту кривую и рабочую точку на ней.

Реальная струя сжимается за отверстием, поэтому расход меньше идеального: коэффициент расхода C_d ≈ 0,62 для острого края. Время опорожнения бака площадью Aₜ через отверстие a:

**t = (Aₜ/(C_d·a))·√(2H/g)**

Для Aₜ = 0,5 м², a = 1 см² (d ≈ 11,28 мм), C_d = 0,62, H = 1 м получается **3641,3 с = 60,69 мин**. При d = 11,3 мм выходит 3630,9 с — разница 0,3 %.
