## Как пользоваться
Голубую стрелку (предмет) и серую вертикаль (экран) можно тянуть мышью или пальцем прямо по сцене; ползунки `d`, `h` и положение экрана дублируют это. Переключатель **Тип** меняет линзу на рассеивающую, ползунок `|F|` задаёт фокусное расстояние. Кнопка **«Экран на изображение»** мгновенно ставит экран в плоскость действительного изображения — и картинка становится резкой.

Следите за тремя цветными лучами от верхушки предмета: там, где они сходятся (или сходятся их пунктирные продолжения), и рождается изображение. Блок «Расчёт» показывает `f`, увеличение `Γ` и численную проверку формулы `1/d + 1/f = 1/F`.

## Физика

Для тонкой линзы в школьном правиле знаков (d > 0 для действительного предмета, f > 0 для действительного изображения, F < 0 для рассеивающей линзы):

**1/d + 1/f = 1/F**,  **Γ = |f / d| = |h′ / h|**

Знак `f` решает всё: `f > 0` — изображение **действительное**, перевёрнутое, образуется по другую сторону линзы и **проецируется на экран**; `f < 0` — изображение **мнимое**, прямое, по ту же сторону, что предмет, и на экран **не ловится** (модель честно это говорит). У собирающей линзы (`F > 0`) картина меняется с расстоянием предмета:

- `d > 2F` — действительное, перевёрнутое, уменьшенное;
- `d = 2F` — действительное, перевёрнутое, равное по размеру;
- `F < d < 2F` — действительное, перевёрнутое, увеличенное (принцип проектора);
- `d = F` — изображение на бесконечности, лучи после линзы параллельны;
- `d < F` — мнимое, прямое, увеличенное (лупа).

Рассеивающая линза (`F < 0`) при любом предмете даёт только мнимое, прямое, уменьшенное изображение — проверьте это переключателем типа.
